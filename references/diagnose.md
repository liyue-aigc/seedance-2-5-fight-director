# 提示词诊断与优化（diagnose）

> 接收用户已有的打斗提示词（或生成成片的反馈），定位问题并给可直接使用的优化版。通用质量规则见 `shared-core.md`，结构推导见 `core-engine.md`，动作/空间/机位语法见 `grammar-library.md`，镜头侧故障对照见 `fight-camera-library.md` 第七节，平台与素材合规见 `seedance-adaptation.md`。

## 诊断流程

1. **还原设定卡**：先从原稿反推十组参数（力量关系、主导内容、空间模式、节奏偏好、胜负变化等，见引擎 §1），判断结构是剧情推出来的还是套了固定范式；仙侠或科幻再加读各自 playbook。用户要求转换打法或题材时，重推相关参数，区分"只换渲染"与"力量/科技系统也要重写"。
2. **五维体检**：按实战五维公式逐项过（权重为经验配比，不是平台参数）：
   - 核心对抗主体 20%：角色差异（身份/体型/装备/能力色）、双方目标、实力关系是否成立；
   - 物理受力与动作状态 30%：七拍是否完整、命中/格挡/落空是否分明、受力先后、支点与距离、重量感与疲态；
   - 环境场景 15%：空间锚点、天候光向、环境参战与破坏累积；
   - 分镜构图与运镜 20%：每镜目的、主运镜唯一、转场方式、景别节奏、高速可读性、机位可行性；
   - 视觉风格与渲染 15%：渲染配方锁定、配色谱系、特效生命周期、声音层。
3. **过能力框**：对照引擎 §6 检查区域数、新元素引入时点、事件密度、高风险机位与介质穿越写法；成片反馈优先核对后半段（长程注意力衰减的高发区）。
4. **逐句定位**：引用用户原文句子定性，不凭印象泛评；没有原文或成片时，明确说明是"通用风险提示"，不冒充已观测故障。
5. **给修法与优化版**：每条问题配可执行改法；用户要优化版时给完整可复制提示词（含【】分块）。

## 六类问题清单

### A. 模糊（抽象替代画面）

- "快速出拳、猛烈踢腿、招式凌厉、特效炸裂、史诗级战斗"——没有可拍动作。
- 修法：替换为七拍具体描述（谁、从什么支撑、沿什么轨迹、打哪、对方怎么应对、接触与否、受力后怎样）；情绪用可见细节（咬牙、瞳孔骤睁、额角汗、护臂凹陷）替代形容词。

### B. 缺失（环节不全）

- 七拍缺环：只有攻击没有应对，或只有命中没有受力结果；
- 技能缺生命周期：挥手就炸、没有积聚与消散；
- 缺空间锚点/天候光向，镜头一切就换世界；
- 缺声音层、缺结束状态、缺胜负变化；
- 多素材未拆职责（一张图同时锁人和场景）、有 @Image 标签但实际无图；
- 高速片缺高速现象（残影、背景后掠、动态模糊、衣发拉直线）与遮挡转场点。

### C. 冲突（读不通或模型做不到）

- 时间预算：每秒超过 3 个主要动作；3 秒内塞俯冲＋穿障＋落地＋重战＋决胜；
- 物理矛盾：无支点连续腾空、空中自由变向、打空却有人倒飞、击退十米却原地站着、距离瞬间消失、武器瞬移；
- 镜头矛盾：一镜到底里写"切特写/反打"；一拍内同时环绕＋推镜＋变焦；急推同时要求距离不变；
- 状态矛盾：同一击既被闪开又出命中效果；对波僵持无进退；大招后双方毫发无损；
- 科幻矛盾：无推进或接触却在零重力急转/刹停；弹体尚未到达目标就先爆炸；护盾未启动或已破裂却继续无损承击；重型机甲像人体轻飘翻转；高功率主炮无限连发却没有供能、后坐、热量或冷却状态；受损推进器、关节、传感器下一镜自动恢复；
- 平台冲突：时长/比例不在枚举内、30 秒以上误用长视频假设、续写方向不明（"向前续写"）、素材数量超限（以 `seedance-adaptation.md` 与实际入口为准）。

### D. 风格不一致（本 Skill 翻车高发区）

- **节奏线混用**：高速流动片里写长蓄力对波/慢动作英雄重击（实测会变成"过家家"回合制）；回合片里全程同等高速导致没有高潮；割草片里主角落地与单体缠斗。
- 配色混乱：一场战斗超过两套谱系、每技能一色的彩虹轮播、仙侠片混入赛博 HUD/西式英雄光束。
- 渲染混搭：3D 国漫片混用平涂速度线（热血番除外）、水墨片塞赛博光效、写实片无来源超能力。
- 镜头形式与题材不符：写实近战默认一镜到底却写多节点快切；群战割草用长定格。
- 特效与动作脱节：特效从头亮到尾、遮住接触点与人脸；对波像两条霓虹灯（无交界线进退与身体反应）。
- 科幻只剩外壳：把仙侠灵力词替换成“量子/等离子”却没有推进、弹道、护盾范围、热量/弹药、结构传力与故障账本；或用满屏 HUD、霓虹光带和球形爆炸替代战术动作。

### E. 平台与素材合规

- 时间戳段重叠/遗漏、结束时间不等于总时长；
- @Image/@Video/@Audio 标签编号与实际素材不一致或无中生有；动作参考视频未声明借用区间与"不继承人物/场景/声音"；
- 伪 API 参数、权重数字、"保证生效的负面提示词通道"、未核实的按钮名；
- 续写未区分原片之前/之后；编辑指令缺"保持不变项"。
- 具体规格读 `seedance-adaptation.md`，不在诊断文件里复述可能过期的数字。

### F. 模板化与平台可行性（本 Skill 翻车高发区，优先排查）

- **模板化输出**：不同需求产出同一套区域序列、时间轴或结尾（动不动云海闭环、五段对波、冷开场割草）；出现用户没要求的既往示例元素。修法：回到引擎重推设定卡，波段与区域由剧情推出；`presets.md` 只给坐标不给路线。
- **后半段新增场景元素**：约 60% 时长后出现未建立的地标、巨物、敌种（实测会被模型自由发挥成无关建筑或怪物）。修法：新元素前移到前 60% 并在前 2 秒建立锚点，或删除；高保真需求转分段版。
- **介质层漩涡化**：穿云/穿水/穿雾写成"环形空洞、撕开云层、到达云层之上"，成片变成对称涡眼的传送门，人物从未真正穿越。修法：按语法库 §4 三段式（介质几何→穿入遮满→穿出定向，穿出后镜头朝下看见介质表面）。
- **高风险机位翻车**：绕弧 180°换位、"A 掠过停到 B 身后"（实测主客颠倒、前景定格、观感滑稽）、脱手小物体跨画面飞行（消失或原地竖立）、长垂直穿层后精确回场（被吞或硬切）。修法：查语法库 §6 黑白名单逐条替换为安全机位。
- **事件密度超标**：最后 3 秒塞俯冲＋穿障＋落地＋重战＋决胜；长遮挡（近 1 秒全灰雾/黑帧）造成空镜。修法：按成本表拆波段，遮挡满画 ≤1 秒且保留运动残影。
- **长时长资产漂移**：无参考图时面部、面具、特定武器在尾段变形。修法：关键道具前 2 秒特写建立，并附资产图提示词（引擎 §7、shared-core §6 第 7 条）。
- **直出/分段错配**：把多区域、三段垂直调度、大规模奇观塞进单段直出。修法：直出版自动降级（减区域、改单向、换安全机位）并注明；同时给分段版。
- **升格变定格（实测）**：慢放段承载了整段倒飞/撞落过程，或受力者身后紧贴障碍无空场，成片变成持续数秒的静态造型。修法：升格只给命中瞬间 0.3–0.5 秒，位移与落地回实时；踢击点放开阔处、落点障碍放飞行前方（语法库 §8、§2）。
- **收尾套路化定格（实测）**：跪地/架刀结尾被拍成正面居高临下的 3 秒胜者摆拍。修法：末 1–2 秒持续后拉或横移、保留喘息衣发余动、静止 ≤1 秒、机位侧后方（语法库 §6）。
- **遮挡字面化（实测）**：满画遮挡变成整屏水墙/黑糊死帧。修法：遮挡约三分之二画幅、边缘留主体轮廓，确需满画 ≤0.5 秒、同段一次（语法库 §5）。
- **特效超时（实测）**：雷网、光效持续 2 秒以上。修法：持续时长写进镜头句子并给残留状态，全屏特效硬上限 1 秒。

## 输出格式

**只要诊断**（默认克制）：

```text
1. 原文："……"
   问题：{A–F 类别 + 一句定性}
   修法：{具体到句子的可执行改法}
2. ……
总体：{一两句最关键的结构性问题与推荐坐标}
```

**诊断＋优化版**：先列关键改动（不超过 5 条），再给完整优化提示词代码块。纪律：

- 保留用户原意与已指定的角色、场景、时长、画幅、结尾、素材绑定；
- 保留用户原结构习惯（尤其用户用了【】分块时沿用其标题）；
- 删掉与新版本冲突的旧约束（如转高速线后删除"蓄力、升格、慢动作"）；
- 优化版必须自洽完整、可直接复制，不输出空占位；
- 用户只要诊断时不擅自整篇重写。

## 坐标转换映射表

转换打法本质是重推设定卡坐标（`presets.md`），波段与时间轴用引擎重新推导，不是换形容词。

| 从 → 到 | 必删 | 必加 | 资产处理 |
|---|---|---|---|
| 蓄力回合 → 高速均势流动 1v1 | 对峙铺垫、长蓄力、对波拉锯、升格/冲击帧、境界碾压 | 冷开场 1–2 秒接触、反馈链条目库（语法库 §3）、均势对手等量进攻、由剧情推出的流动路线、遮挡缝合、≤0.3s 终局微停、脱手/破防胜负手 | 角色/武器/配色保留；法术规模收缩到兵器附着能量 |
| 单人/1v1 → 群战清场 | 单挑博弈、近身缠斗、落地打法 | 统一材质敌群与涌入来源、每轮五拍（引擎 §2）、按几何错开的 3–4 形态技能＋地形改变式终局、持续补入与一次近失、高位机动位移、六件冲击替代 | 主角保留并强化为高位施法者；战场扩为立体大场景 |
| 写实 → 仙侠国漫 | 无超能力限制、手持摄影低饱和 | 力量体系四件事、技能六步生命周期、3D 国漫 CG 渲染配方、修士尺度受力、垂直空间、破坏五级升级 | 角色可升华为修士身份（需一句话标明为创作补充） |
| 群战 → 1v1 | 敌群、技能配额、环形终局 | 单个等量对手、抢角度叙事、反馈链密度、双色兵器体系、由剧情推出的追逐路线 | 主角保留；敌群收束为一名具体对手 |
| 2D 水墨/赛璐璐 ↔ 3D 国漫 | 旧渲染关键词与速度线习惯 | 镜头库第四节对应配方全套锁定 | 动作编排可保留，重锁渲染与特效质感 |
| 仙侠/超能力 → 科幻 | 灵力、法阵、法相、无代价瞬移、武器凭意念出现 | 结构与挂点、推进/惯性、弹道、护盾、供能/热量/弹药、故障账本（scifi playbook） | 可保留攻防节奏与胜负变化；所有力量来源和视觉名词重写 |
| 科幻 → 仙侠/玄幻 | HUD、推进器、枪炮、反应堆、机械报警 | 境界尺度、能力来源、技能六步、法器/身法支点、国风色谱（xianxia playbook） | 可保留位置变化与节奏；科技资源窗口改为灵力、法器或阵法代价 |

## 反馈话术对照表（用户怎么说 → 查哪里）

| 用户反馈 | 最可能的故障 | 处理 |
|---|---|---|
| "像过家家、不够快、不够凌厉" | 坐标选错：写成了蓄力回合或站桩；反馈链断 | 重推为全程实时高速坐标：冷开场、反馈链密度（语法库 §3）、删蓄力升格、加均势对手 |
| "两个人像轮流演招/对手像木桩" | 对手无主动进攻、无即时反馈 | 补均势对手行为与等量攻击发起；每条攻击同拍/下拍长出反应 |
| "特效一塌糊涂/糊成一团/像 LED 灯带" | 无生命周期、多配色、遮屏 | 语法库 §7：六步生命周期、一套谱系、核心特效只在接触点 |
| "人物糊成残影、变脸、多手" | 密度过高、运镜堆叠、素材职责混杂 | 每秒≤3 动作、每拍一个主运镜、主体清晰背景模糊；素材分图锁定；无图附资产图提示词 |
| "场景像换了个世界/背景板" | 无锚点、区域间无路径 | 3–5 个锚点贯穿、遮挡缝合、俯冲看见开场地标；后 40% 不引入新元素 |
| "不够宏大/没有史诗感" | 景别单一、环境不参战、破坏不升级 | 大景建立→小景打→大景确认；破坏五级；修士/法相尺度 |
| "打了半天没感觉/不疼" | 命中先于反馈或无受力 | 先接触后特效；四通道选 2–3 项；材质声对齐；击退留飞行时间 |
| "末段手忙脚乱塞爆/后半段乱了" | 时间预算超红线、长程注意力衰减 | 成本表拆波段；新元素只进前 60%；复杂结构转分段版 |
| "穿云变成大漩涡/传送门" | 介质穿越缺几何与过程 | 语法库 §4 三段式重写，禁涡眼/空洞/竖立云墙 |
| "结尾很滑稽/人站错位置" | 绕弧换位、掠过停身后机位翻车 | 语法库 §6 黑名单替换为正侧面固定机位、同向侧影 |
| "像西方超级英雄/赛博朋克"（仙侠需求） | 视觉体系错位 | 删 HUD/光束对射/科技元素，回国风：法相、符箓、云海、赤金体系 |
| "机甲像人在穿纸壳/没有重量" | 缺支撑足与结构传力，动作套用人类轻功 | 加读 scifi playbook：锁吨位、支撑/推进、关节迟滞、后坐与装甲形变；以中全景保留足部和接触点 |
| "科幻战只剩激光乱射/像霓虹灯" | 无距离层、弹道到达、护盾交互和资源代价 | 固定两种主要武器＋一种防御；写发射源→传播→拦截/命中→热量/弹药/故障；限制系统色与 HUD |
| "太空战方向看不懂" | 无地平线/空间站/舰体主轴参照，镜头与主体同时乱转 | 固定 3–5 个太空锚点和主运动矢量；每次变向写姿态喷口或接触来源；用桁架、舱门、残骸遮挡缝合 |
| "慢动作变成定住摆拍" | 升格承载整段反馈、受力者身后无空场 | 升格只给命中半秒、位移与落地回实时、踢击点放开阔处 |
| "结尾像摆拍合照/定太久" | 跪地架刀被拍成正面静态胜者图式 | 末段持续后拉或横移、加喘息衣发余动、静止≤1秒、侧后方机位 |
| "转场整屏水墙/黑屏" | "遮挡满画"被字面执行 | 遮挡约2/3画幅、边缘留主体轮廓；满画≤0.5秒、同段一次 |
| "技能一亮就停不下来" | 特效无时长上限 | 句内写死持续秒数（如0.8秒）与残留状态 |
| "每次出来都一个套路" | 模板化输出 | 回到引擎从剧情重推设定卡与波段；删除用户没要求的固定元素 |

诊断纪律：先引用用户文本或成片中的实际问题，再选修法；拿不准是坐标误判还是细节缺失时，先给坐标判据结论并允许用户一句话切换。成片诊断优先抽帧逐段比对，区分"提示词没写""写了但用了高风险机位""平台长程衰减"三类责任，再决定改提示词还是转分段。
