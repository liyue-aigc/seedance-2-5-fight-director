# 打斗与镜头库

**本文件是跨题材镜头资产**：基础镜头表、高燃镜头增补、速度用途、五套风格渲染配方（第四节）、动作链配方（第五节）、单镜字段模板（第六节）、故障修复表（第七节）。按当前场景选用，不是镜头必须全部出现的流程。结构与时间配额由 `core-engine.md` 推导（耗时成本表在其 §3），机位可行性黑白名单在 `grammar-library.md` §6，本文件不复制。下列术语是导演描述，不是 Seedance 参数表。

## 一、把镜头写到动作上（基础镜头表）

| 动作节点 | 主运镜与景别 | 写清什么 | 常见误用 |
|---|---|---|---|
| 冲刺接敌 | 低机位全身景，沿运动方向跟进或侧跟 | 双方距离如何缩短；脚步与前景视差 | 一边向迎面冲来的人急推，一边要求距离始终不变 |
| 擦身/错位 | 围绕交错点有限环绕，中景保留双方 | 谁从哪侧绕过，绕行后的位置与朝向 | 突然半圈环绕，角色也转半圈，空间无法辨认 |
| 低位攻击 | 低于膝部的侧跟，保留支撑脚或地面关系 | 哪条腿支撑，另一条腿的路线，对手如何避让或失衡 | 双脚都在踢却没有支撑；镜头只拍一只脚无法识别角色 |
| 起跳/腾空 | 低机位中全景，向上摇摄跟随 | 蹬地、上升弧线、空中动作、落点与支点来源 | 镜头一抬，角色无起跳直接悬浮 |
| 关键接触 | 易读的中近景或局部靠近，落点前减速 | 攻击端、接触面、守势压缩或形变 | 极近特写裁掉出手者，又用闪光遮住接触 |
| 击退 | 随受力者后拉或侧跟，景别适度展开 | 力的方向、后撤距离、脚底与地面摩擦 | 身体朝右飞，碎屑和镜头全向左；离地后瞬间站稳 |
| 连击追身 | 与进攻者同步侧移，中景/全身景 | 步法补距，上一招收势如何成为下一招起势 | 每一拳一个抽动，人物成了模糊轮廓 |
| 对手反制 | 沿已出现的威胁转向或调整焦点 | 起手信号、攻击轨迹、主角识别后的反应 | 镜头先指向空处，攻击凭空出现 |
| 上方压制 | 先建立高度，再向下跟随 | 落下路线、下方目标和接触后果 | 同时要求仰拍面部与俯拍落点却没有移动路径 |
| 尾帧留势 | 中景或中近景缓慢后拉 | 支撑、呼吸、目光与下一步方向 | 战斗中突然面向镜头摆写真姿势 |

“推、拉、摇、移、绕”选一个主要动作即可。视角拉宽只是可选风格意图，不要机械地给每次冲刺加 FOV 变化。

## 二、国漫高燃镜头增补

| 镜头 | 用途 | 必须写清 | 禁忌 |
|---|---|---|---|
| 航拍俯冲建立 | 开场交代宏大战场与双方尺度 | 起点高度、俯冲方向、落点如何引出人物、固定地标 | 俯冲后不给落点，直接切到看不清方位的近景 |
| 极速推镜 Crash Zoom | 大招启动、刃尖/眼神/法阵关键细节 | 推镜起点景别与终点锁焦对象、推动触发时机 | 一拍内既环绕又推镜又变焦；推到全屏光效 |
| 攻击轨迹全程跟拍＋终点定点锁焦 | 高速冲刺斩、飞剑、突进 | 跟拍对象、终点锁焦点、背景相对高速后掠与动态模糊 | 轨迹中途换主体；拖尾实体化、长时间不消散 |
| 多节点快切 | 白热化连招、结印/换招瞬间 | 每个切点的动作趋势、屏幕方向延续、切点总数（每段 2–4 个） | 每 0.5 秒无理由切一次，切点不接动作 |
| 冲击帧 Impact Frame | 最重的一次碰撞 | 触发帧（接触瞬间）、样式（白闪/黑场/单色水墨爆点）、时长极短立即回到动作 | 每次碰撞都闪；闪光超过一瞬遮住结果 |
| 短促升格 | 决胜一击、对波反推、击飞瞬间 | 触发点、约 0.4–0.5 倍速区间、何时回正常速度并计入总时长 | 全程慢动作；慢放段里还要完成整套连招 |
| 终招定格/微停 | 收势造型、剑气裂痕蔓延 | 定格前的动作惯性、定格时长（约 0.3–0.8 秒）、之后的环境余动 | 角色突然摆拍；世界全部静止只剩人站着 |
| 有限环绕 | 兵器相抵、蓄力对峙、胜负落定 | 环绕弧度（建议 ≤180°）、谁动谁不动、绕行后方位 | 360°环绕同时要求读清手部细节 |
| 垂直空间调度 | 踏柱而起、空中接力、打向高空/击落深渊 | 每层支点、上升/下落弧线、高度参照（云、断柱、深渊） | 无支点连续腾空；高度忽高忽低 |
| 俯冲/坠机跟拍 | 从天而劈、击落对手 | 坠落方向、前景掠过物、接地瞬间与缓冲 | 坠地无缓冲直接站起 |
| FPV 穿行 | 穿过法阵、碎屑、竹林、建筑缺口接战 | 穿行路径上的前景物、出口朝向与主体关系 | 穿墙穿人；出口朝向与轴线矛盾 |
| 遮挡转场 | 隐形切镜的主力 | 遮挡物（掠过的身体/魔气爆散/落石/甩镜）满画、遮后新机位的起点状态 | 遮挡前后人物位置、朝向、动量不连续 |

## 三、五种速度用途

- **快速跟拍**：与主体同速，背景与近景产生视差，主体相对清晰。适合接敌和追击。
- **短促甩镜**：把视线转移到新威胁或沿攻击弧转动；在落点前收住。适合突然变向，不适合全程。
- **短暂停顿感**：只在主要接触点略压低时间流速或运动幅度，再释放余势，不能凭空增加总时长。
- **短促震动**：受力触发且有方向，快速衰减。不是让相机从头到尾乱晃。
- **缓慢后拉/稳定停留**：给观众读出战果、距离、呼吸和未消失的威胁；宏大收尾常用后拉成大远景。

避免“始终高速、全程慢动作、每次碰撞定格、全程完全稳定”并列。用户要求无慢动作时，以动作间短暂停手或呼吸形成节奏，不改变播放速度。

## 五、动作链配方

### 拳脚：一次进攻与一次反制

`前脚落稳 → 出拳试探 → 对手格挡，守势被压紧 → 进攻者收拳 → 对手借空档反击 → 进攻者移步躲开 → 双方重新形成可攻击距离`

再按故事需要增加一个决定性动作。不要把“直拳、肘击、旋踢、背摔、腾空飞膝”挤在同一两秒内。拳、肘、腿的有效距离不同，必须有接近或退让。

### 腿法：轨迹与落地

`支撑脚稳定 → 髋部带动攻击腿划弧 → 对手护住或退开 → 接触/落空后顺势收腿 → 落地恢复平衡 → 下一步启动`

起跳腿法应加入可见蹬地和落地缓冲。镜头至少在关键阶段让观众看见脚与地面的关系。

### 兵器：路线交叉与余振

`明确握持与朝向 → 挥动路线 → 对方兵器进入阻挡路线 → 两件兵器接触 → 刃/杆振动与双方承力 → 分离或沿接触点滑开 → 重设距离`

刀剑不要无接触就喷火花。武器被锁住时，后续攻击必须先解开或利用锁住状态。

### 摔投/击飞：重心先变，再位移

`可见接触或力场到达 → 原支撑被破坏 → 身体沿受力方向倾斜或离地 → 空中运动延续（衣发、脱手物同向）→ 地面/墙面/石柱接触 → 缓冲、滚动、滑行或坠渊 → 最后停稳`

只写“被打飞十米”会丢失重量，须补来源与落点；写实风格降低飞行距离，仙侠风格要写明是剑气/掌劲/冲击波哪一种力、何时到达。时间不够呈现完整落地时，结尾可停在仍在滑行或坠落的中间状态。

### 仙侠技能：六步生命周期

完整六步生命周期（积聚→引导→传播→相遇→响应→消散）、对波因果链与护盾等价写法是通用规则，唯一维护处在 `grammar-library.md` §7，本文件不复制。

### 魔物：威胁显形与尺度

`肩背/肢体先收紧 → 重肢或尾部开始扫动 → 人物识别并离开路线 → 重肢击中原位置或被挡住 → 地面与体表发生符合尺度的响应 → 新的空档出现`

攻击器官要在画面中有来源；触手从哪里伸出、绕过哪里、到哪里停止都要可理解。

### 机甲：结构传力

`足部抓地/推进器启动 → 髋部和肩部带动重臂 → 装甲接触 → 活塞压缩、关节回弹或外壳局部变形 → 质量转移到支撑足 → 稳定或滑退`

能量护盾要有开启位置、接触范围与耗散。推进惯性、弹道、导弹、主炮、护盾扇区、热量/弹药与故障账本的完整规则见 `scifi-combat-playbook.md`，本镜头库不复制。

## 六、分镜时间轴与单镜字段

### 单镜字段模板

`时间区间｜镜头目的（建立/威胁/攻防/重击/结果）｜景别与机位｜主体动作（七拍关键环节，每秒≤3个主要动作）｜运镜（一个主运动）｜技能/特效（所处生命周期阶段）｜环境与声音｜结束状态（位置、朝向、距离、动量、伤损/资源、握持）`

### 时间配额原则

- 时间戳一律由 `core-engine.md` §3 耗时成本表反推：列波段、波段内列动作、查成本求和、超预算按规则删减；本文件与任何手册都不提供固定时间表。
- 通用密度：一个镜头一个叙事目的；5–8 秒承载一个威胁、一次应对、一个可读结果；10–15 秒容纳两三次主要交锋与一次显著变化；决胜波段前后各留至少 1 秒读结果。
- 一次完整的"腾空下劈＋格挡＋震退"至少留 2–3 秒；俯冲穿障与落地重战分属两个波段，不塞进同一 3 秒。
- 单段直出的区域数、新元素引入时点与高风险机位限制，统一见 `core-engine.md` §6 能力框与 `grammar-library.md` §6 机位黑白名单。

## 七、常见失败与修复

| 表现 | 提示词中的可能原因 | 具体修法 |
|---|---|---|
| 动作很多但不燃 | 每招同样力度，对手像靶子；没有回合劣势 | 减招，设置招架或反制，安排一次明确失势，再突出一次决定性交锋 |
| 打空却有人倒飞 | 攻击结果含糊；效果先于接触 | 明确命中/格挡/落空，补上力的到达与身体反应 |
| 镜头快但看不清 | 同时多种运镜，整屏模糊遮挡 | 每拍保留一个主运镜，接触前减速，清晰主体 |
| 身体像橡皮 | 缺少支撑、距离、关节和恢复 | 写出落脚、转体和收势；减少同时发生的肢体任务 |
| 技能像贴画/LED 灯带 | 只有“释放蓝光”，没有积聚与衰减 | 补六步生命周期：写能量从哪来、沿什么走、碰到什么、如何散 |
| 对波像两条霓虹灯 | 没有交界线进退和身体反应 | 写交界线推移方向、弱势方犁地颤抖、反推触发动作与结果 |
| 特效糊成一团 | 发力、命中、爆炸同时开始；两色以上技能混战 | 限定一套色彩谱系；分清释放/传播/接触/消散；压低特效覆盖面积 |
| 角色全程在天上飞 | 身法无支点 | 给每个腾空写支点（蹬地、踏柱、御剑、法阵）与落点 |
| 宏大场景像背景板 | 锚点只在开场出现，环境不参战 | 每镜保留 1–2 个锚点；让斩波、气劲、坠落物改变环境 |
| 分镜像重开一局 | 切镜后站位重置、伤损消失 | 每镜写明结束状态，下镜从该状态的位置、朝向、动量、伤损接起 |
| 人物被换脸换衣/多肢 | 参考职责混杂，动作密度过高 | 角色图锁完整外观，动作视频只借动作；每秒≤3个主要动作，连招分镜拆开 |
| 一镜到底变蒙太奇 | 出现切镜词，或景别跳变无路径 | 把切镜改为连续移动并给移动时间；无法兼得时明确改用分镜剪辑 |
| 慢动作太多像摆拍 | 每击凝滞，蓄力过长 | 全片升格限 1–2 次、冲击帧限 1–2 次，其余流畅实时 |
| 声画有冲击但失真 | 材质声不匹配或音效提前 | 对齐真实接触，区分破风、材质、低频与余响；法术用嗡鸣/锐音而非金属声 |
| 技能像彩虹轮播 | 神通池只罗列不排序，每技能换一种颜色 | 30 秒选定 3–4 种＋终局并固定先后；主色统一，辅助色少量 |
| 魔潮像背景板 | 敌群只在远处飘、不反击、不爆散 | 写明涌入方向与密度变化、每轮反扑与一次近失、击中后的流体爆散与密度空缺 |
| 割草像站桩播片 | 主角原地连续挥手，瞬移没有位移 | 每次施法后瞬移/折返/俯冲改变机位高度与方位，写清起止位置，上一收招接下一起手 |
| 高速剑术像轮流演招 | 只有攻击没有即时反馈，双方各打各的 | 以反馈链为单位：格挡→偏转→闪避→反攻，每击同拍或下一拍必长出对方反应 |
| 敌人像陪练木桩 | 对手只防守不进攻，实力一边倒 | 给对手等量的主动进攻、追击、反击与闪避，用角度得失而非血量推动交换 |
| 跨区域像换了个世界 | 区域间无路径无遮挡，高空地面像两个场景 | 写带时间的空间路线与每段遮挡物，俯冲时看见开场地标，破坏状态带回起点 |
| 高速段人物糊成残影 | 镜头与主体同速失控、特效遮人 | 全景中景为主、每拍一个主运镜，主体保持清晰，用背景动态模糊表现速度 |
| 末段事件塞爆 | 3 秒内俯冲+交剑+穿障+落地+重战+决胜 | 按成本表拆波段：俯冲穿障与落地重战分属两段，终局只留连段+一次胜负手 |
