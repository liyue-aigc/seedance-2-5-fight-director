# 仙侠国漫高燃打法手册（题材词汇与物理）

本手册只服务仙侠、玄幻、志怪、国漫斗法题材的**词汇、力量体系与视觉物理**，与主 SKILL 的推导引擎（`core-engine.md`）、通用语法（`grammar-library.md`）、镜头库配套使用。本手册不含剧情结构、固定顺序与时间戳——任何波段、路线、时间轴都由引擎从剧情推导。目标质感：《雾山五行》式 2D 硬核、《完美世界》《斗破苍穹》年番式 3D 国漫电影级 CG 的高燃战斗——场景宏大、招式迅捷、受力真实、特效自然连贯。所有关键词是导演描述，不是平台参数。

## 一、先立力量体系

动笔前内部确定四件事，不一定要展示给用户：

1. **境界与尺度**：本场是武者级（碎石裂木）、修士级（崩台断岳、凌空斗法）还是巨兽/法相级（移山填海）？尺度决定受力反馈上限（对照 `grammar-library.md` §2 尺度表），修士不能打出凡人量级，凡人也不能无缘由硬接修士一击。
2. **能力来源**：剑诀、灵力、丹田、法器、符箓、法阵、妖兽内丹、魔气……每个技能都要回答“力从哪里来”。
3. **风格差异**：刚猛（重兵器、大开大合、弧光厚重、步震地面）对灵动（轻兵器、高速位移、残影密集、点到即走）；远程压制对近身搏杀；数量对单体。差异越大，碰撞与戏剧冲突越强。
4. **胜负手**：从 `core-engine.md` §4 通用目录选本场唯一胜负变化（破护体、兵器脱手、对波反推、法阵被破、力竭、地形杀等），并提前埋线索（如护体光纹在前期被击出裂纹）。

## 二、对抗主体的具象化

避免“两名修仙者对决”这类空描述。按四要素写具体：

- **身份气质**：青年剑修（冷峻、以巧破力）／黑甲魔修（暴戾、以力压人）／道门符箓师／妖狐／金刚武僧。
- **体型差异**：身高近两米的重甲魔修 对 身形修长的白袍剑修；十丈巨兽 对 踏剑少女。体型差同时规定速度差与惯性差。
- **装备**：长剑/重刃/长枪/折扇/法铃/伞面法阵/锁链/巨弓；写清握持方式、材质微光、归属（不互换、不凭空出现）。
- **能力视觉**：青蓝剑气、暗红魔气、金色法相、幽蓝狐火、墨色水韵——一场战斗限定一套对立配色，正奇/正邪分明。

## 三、技能设计库与写法

### 剑气/刀气

- 积聚：剑身纹路逐段亮起，灵力沿剑脊汇聚到剑尖，空气扭曲、脚下碎石浮起。
- 释放：挥剑动作引导剑气沿斩击弧线离体，形态是“弧光”或“一线”，不是持续光柱。
- 传播：剑气有长度与飞行速度，沿途切开雨幕/云层/水面，留下快速消散的尾迹。
- 相遇：与兵器相格挡开火星与冲击波；与对向剑气碰撞后炸裂或互相湮灭。
- 消散：命中后光效迅速收束，留下裂痕、断口、缓慢飘落的碎屑，光不持续铺满画面。

### 法术对波（beam clash）

完整因果链：`蓄力（双手结印/法器高举，能量球压缩到极致，衣发被吸向中心）→ 轰出（能量沿直线推进，照亮整片战场）→ 相遇（两色能量在画面 1/3 处相撞，交界线形成）→ 拉锯（交界线向弱势方缓慢推进，弱势方脚下犁出深沟、护体光纹闪烁、咬牙渗血、后脚蹬碎石面）→ 反推（强势方加力或弱势方爆发，写清触发动作：剑指变换、第二张符箓点燃、怒吼注入灵力）→ 洞穿（一方能量被撕碎，冲击波环形扩散）→ 命中与战果（被击中者沿力向飞出、护甲裂开、撞断石柱坠入云海）`。

对波镜头：蓄力用特写（眼神、结印手指、剑身），对波用中景/远景看清交界线与双方姿态，反推瞬间可用一次冲击帧或短促升格，随后恢复实时速度。

### 法阵/符箓/法器

- 法阵：写明出现位置（脚下/半空/伞面）、旋转方向、层数与符文亮起顺序；法阵是力的来源，启动后角色的动作才有对应效果；被破时符文逐行熄灭、碎裂成光点。
- 符箓：画符/掏符/甩出/点燃/化光要有动作过程；纸鸢、纸人、锁链等“化生法器”写明从什么器物飞出、化成什么、如何收回或消散。
- 法器牵引：金丝锁链缠尾、飞剑回旋、法铃震波——写清连接关系与绷紧/松弛的受力反馈，被缠住的一方要有挣脱动作与方向。

### 身法

- 踏空/御剑：脚下出现灵光点或剑体作为支点，每次借力有可见的蹬踏动作与衣发惯性；上升有弧线，不是垂直漂浮。
- 缩地/瞬影：用“残影＋背景高速后掠＋动态模糊”表现高速，本体始终可辨认；残影 2–3 道、快速淡出，不变成分身。
- 空中接力：踩断柱、踏剑身、借对手兵刃变向——每个支点都要在画面中真实存在，踩中后支点要有受力反应（柱断、剑沉）。

### 护体/护甲

- 护体灵光：受击位置先出现光膜凹陷/波纹，再决定挡住还是碎裂；被连续重击时光纹出现裂纹并逐次变暗，为最终破防埋线索。
- 重甲：斩中重甲先见火花与斩痕，重甲卸去部分力但身体仍随冲击位移；裂口随攻击累积，不一次完好一次粉碎。

### 大型神通视觉菜单（群体清场类战斗的备选池，选定后固定）

仅当剧情推导出"个体对波次"或需要大规模法时时，从本菜单按几何维度**错开选取 3–4 种＋1 个终局**，固定出场顺序，不照单全塞、不连续放两种同形态技能：

- 雷霆神龙（横向扫荡的线/面）、帝威镇压（法相垂直下压）、焚天神火（流体火海，面）、神水怒涛（跨战场洪流，面）、神箭贯日（多道长线贯穿，线/点）、开天裂界（纵向/斜向切割空间）、万丈法相（多方向神圣光芒压制）、巨型神兵法则（能量构造横扫，非主角手持实体武器）、多法宝齐射（多方向同时打击）、终局归墟（环形法则冲击，调动前面全部元素）。
- 终局不要普通球形爆炸：必须同时改变空间、介质（云海/水面）、敌潮与地形（对应语法库 §9 第五级）。
- 选择规则：相邻技能形态按点/线/面/立体几何错开；主角全程空手施法时禁止随机出现实体主武器，巨型神兵只能是能量构造。
- 群体清场的波段推导（五拍轮转、密度只增不减、一次近失、位移换位）由 `core-engine.md` §2 统一规定，本手册不重复。

## 四、仙侠战场词库

### 空间锚点备选（开场固定 3–5 个，全片保留）

- 主地标：断裂石桥、倒塌的镇妖石柱、倾斜山门牌匾、悬浮石台、古树干、湖面、塔顶。
- 纵深参照：云海、深渊、远山、雷暴云墙、漫天飞雪、飘飞红叶——给高度和距离做标尺。
- 光源与天候：金色夕照云缝、雷暴闪电、满月逆光、丁达尔光束、法宝冷光；定死光向与主色调。
- 开场用一个航拍俯冲或大远景把锚点与双方位置一次交代清楚；之后每镜至少保留一个锚点，防止空间漂移。

### 垂直空间与介质

仙侠战场天然立体，但高度路线由剧情的空间模式（引擎设定卡第 4 组）决定，不自带"升空穿云再返回"的固定闭环。设计高度变化时写"高度路线图"：每层的支点、高度参照物、落回下层的缓冲；上升用低机位仰摇，坠落用俯冲跟拍，大远景确认人与深渊的尺度。

涉及云海、水面、雾层、火幕、烟墙等介质穿越时，**必须按 `grammar-library.md` §4 介质层穿越三段式写**（介质几何→穿入遮满→穿出定向）：禁止漩涡、涡眼、对称双涡、传送门式云洞、竖立云墙；"到云层之上"必须有穿越过程并在穿出后镜头朝下看见云面。"穿到云上再俯瞰返回"的三段垂直调度超出单段能力框，直出版只写单层，完整版走分段（引擎 §7）。

环境破坏的五级升级与"方向服从受力"是通用规则，见 `grammar-library.md` §9，本手册不另立标准；仙侠语境的逐级表现为：衣发落叶积水微动 → 石面裂纹/踏碎石台 → 斩波断柱/碎石掀飞/云海冲开漏斗形缺口 → 整段桥塌/巨石落渊/云层撕开露天光 → 碎石沉降、云海回填、残骸裂痕留画。

## 五、情绪与张弛词库

- 节奏曲线（哪里快、哪里慢、高潮在哪）由 `core-engine.md` 按力量关系与波段推导，本手册不规定固定时间点；"一张一弛"坐标的蓄力低速点与决胜最高速点见 `presets.md`，冲击帧/升格配额见 `grammar-library.md` §8。
- **情绪即力量**：用可见的面部与肢体细节替代抽象情绪。词库：咬紧牙关、瞳孔收缩后骤睁、眉骨紧皱、青筋暴起、额角渗汗被风吹散、嘴角溢血、怒吼时灵力随气息喷涌、眼神从凝重到决绝。情绪与波段绑定：蓄力时咬牙、反推时怒吼、被击时面部扭曲。
- **英雄重击只有一下**：把最重的镜头预算（冲击帧＋升格＋Crash Zoom＋音乐爆发）集中给胜负手，其余交锋流畅实时带过。
- **张弛信号**：慢下来的方式可以是一次兵器相抵的角力、一次擦肩后的短暂定格、一片在高速中缓慢飘落的叶子/雪花——用局部慢速反衬整体高速；全程高速片则用动作密度与景别变化呼吸，不使用慢动作。

## 六、视觉与声音词库（按需取用，不堆砌）

- **高速现象**：白色/青色残影、速度线、背景高速后掠、边缘动态模糊、脚步连环炸开水花、衣发与长缨被拉成直线。
- **技能质感**：剑气弧光、灵力粒子上浮、能量核心压缩发亮、电弧游走、水墨晕散、光膜涟漪、符文逐字亮起、粒子重聚。
- **冲击瞬间**：接触点环形冲击波、空气波纹、放射状光爆、单帧白闪/黑场、镜头短震、火星与碎屑沿力向飞溅。
- **余势**：剑身余振、光纹明灭、尘雾沉降、碎石坠落、衣摆缓缓落下、呼吸白雾、雨丝重新变得清晰。
- **声音**：剑鸣（出鞘清越龙吟）、破风（SWOOSH/WHOOSH）、兵器交击（CLANG 短促金属）、法术（低频嗡鸣积蓄→释放时轰响）、雷法（炸裂 ZAP/雷鸣）、剑气（尖锐破空＋织物撕裂感）、巨石（CRUNCH/沉闷低频）、环境（罡风、云海雷声、落石坠渊渐远）。配乐用鼓点与弦乐：压制段鼓点加密、蓄力段抽空到近乎静音、反推瞬间全奏、胜负后戛然收住留风声。

## 七、仙侠专属避坑

- 光效堆满全屏、从头亮到尾 → 限定核心特效只在接触点，运动过程只给辅助特效，给光效消散时间。
- 技能没有起手，挥手就炸 → 补结印/聚气/法器动作，让观众预读到威胁。
- 蓝红两团光乱撞、看不出谁占上风 → 固定交界线位置与推移方向，给双方身体反应。
- 角色无限腾空、空中自由变向 → 每个空中动作写支点与惯性。
- 大招对波后双方毫发无损继续快打 → 对波必须产生可见结果：击退、破甲、兵器脱手、力竭喘息。
- 斩击切山裂石但人物像没受力 → 先有身体反馈（守势压缩、后脚犁地），再放环境破坏。
- 飞剑/法器越界变成第三、第四个角色 → 法器是道具，写清操控者与归属，化生单位数量固定且可清点。
- 国风变成古风元素拼盘 → 锁定一套渲染配方与色调，水墨片不塞赛博光效，3D 国漫片不混用平涂速度线（热血番风格除外）。
- 30 秒塞十几个招式 → 减到 2–3 次主要交锋＋1 次对波/决胜，每招读得清比招式多更燃。

## 八、与推导引擎的配合

仙侠不自带任何固定节奏路线。调用仙侠题材任务时：读本手册（力量体系、技能配方与神通菜单、战场词库、视听词库、避坑）＋ `core-engine.md`（设定卡与波段推导）＋ `grammar-library.md`（通用语法），口味坐标用 `presets.md` 与用户确认：

- 近身拳拳到肉的写实武侠 → 写实近身短打坐标，不用超自然特效；
- 蓄力对波、境界压制、升格决胜 → 蓄力回合决胜坐标，对波按本手册第三节因果链写全；
- 实力接近、攻防不停、满场流动的双人高速战 → 高速均势流动 1v1 坐标，法术规模收缩到兵器附着能量；
- 仙人/法修对魔潮、兽潮、军团的清场奇观 → 群战清场坐标，神通从本手册第三节菜单按几何错开选取。

坐标可以自由混合（如守卫宗门的群体防御战、追逐中边逃边打的立体追杀），波段与时间轴一律由引擎从剧情推导，不套用任何固定区域序列。
