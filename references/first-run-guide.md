# 首次调用简短教学

只在 `scripts/first_run.py claim` 返回 `show_tutorial: true` 时自动展示，之后不因新对话重播。用自然中文简短告诉用户：

> 第一次用这个 Skill：告诉我“谁和谁打、在哪打、想要多快/多华丽、打多久、结尾怎样”即可；没说全我会合理补齐。你也可以要求“只输出可复制提示词”“给分段版”或“诊断现有提示词”。例如：`用 $seedance-2-5-fight-director，写30秒女刀客对男枪客，从古殿打到云海，全程高速均势、特效华丽、无蓄力慢动作，结尾长枪脱手，只输出提示词。`

随后立即完成当前请求，不要求用户先回答教程问题。用户有严格输出格式时，将本段教学放在前置消息，保持最终交付内容可直接复制。
