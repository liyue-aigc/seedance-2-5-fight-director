# 新手指引（getting-started）

> 按需查阅的完整使用说明。首次实际调用只自动展示 `first-run-guide.md` 中的简短教学，是否展示由本机持久标记决定；新对话不重播本指引。用户已经给出明确需求时，教学后直接执行，不强制展示整篇说明。

## 这个 Skill 能做什么

把任意题材的一句剧情描述，推导成 Seedance 2.5（即梦/Dreamina）可直接复制的高燃打斗提示词。它不是模板填空：每场戏的波段、路线、时间轴和结尾都由你的剧情本身决定，仙侠、武侠、现代格斗、西部枪战、机甲巨兽、太空战、一挑多都适用。四类产物：

1. **导演执行脚本**（默认，20 秒以上复杂打斗）：【全局画质】【整体战斗概念】【角色资产】【武器/能力/科技系统】【世界场景】【视觉特效体系】【战斗原则】【镜头语言】【声音设计】【分镜时间轴】【全局负面约束】分块正文 ＋ 一段含同样分块、可直接复制的最终提示词。
2. **省事直出版 / 高保真分段版**：复杂大场面默认同时给两版——直出版自动把模型单段拍不稳的内容降级到可行范围；分段版按遮挡点切成 5–7 秒小段，供后期拼接。
3. **资产图提示词**：没有角色/武器/场景参考图时，自动附带可直接用于文生图的三视图与场景提示词，不用你自己再写。
4. **诊断与优化**：贴进已有提示词或拿成片反馈，指出模糊、缺失、冲突、模板化和平台可行性问题，并给改好的版本（也支持换打法、换题材）。

## 怎么调用

- 标准调用：`使用 $seedance-2-5-fight-director，{你的需求}`
- 一句话也行：`用这个 Skill 做一段高燃打斗：{谁和谁、在哪、为什么打、结局怎样}`——信息没给全时，用合理默认直接写，最多问你 1–3 个大白话问题。
- 有参考素材时：`图1锁角色A，图2锁角色B，视频1只借2–6秒的动作节奏，不借人物和场景。`

## 你只需要说清楚一件事：这场打斗是怎么回事

自然描述即可，例如"机甲战士被虫群包围、队友及时救场""两个枪手正午小镇对决""守城兵挡一头攻城巨兽"。Skill 会自动推导力量对比、打法内容、空间路线和节奏。

你可以提供但**全都可以不填**的信息：

| 信息 | 说明 | 不填时的默认 |
|---|---|---|
| 角色与人数 | 身份、外观、体型差异、人/机甲/巨兽/群体 | 两个原创成年角色 |
| 想要的感觉 | 拳拳到肉 / 大招对轰 / 高速追着打 / 横扫千军 / 守住阵地 | 按剧情自动匹配，可用一句话确认 |
| 场景 | 地点、天气、光线、可破坏物 | 与题材匹配的单一战场 |
| 武器或能力 | 兵器、法术体系、科技系统、配色 | 按角色身份补一套可读的战斗系统 |
| 时长 / 画幅 | 如 30 秒、16:9 | 15 秒、16:9（竖屏素材推 9:16） |
| 结局 | 脱手/破防/打停/逼退/守住/救场成功 | 有明确胜负变化，默认不击杀、不毁机 |
| 参考图/视频 | 角色、武器、场景、动作或镜头参考 | 纯文生，并自动附资产图提示词 |
| 音频 | 对白、BGM、静音 | 无对白无字幕，环境声＋配乐 |

不确定想要什么感觉时，只需回答一个大白话问题：**"想要近身拳拳到肉、双方蓄力大招对轰、两个人高速追着打、一个人横扫千军，还是死守一块阵地？"** 题材与感觉分开选："高速追着打"既可以是仙侠刀剑，也可以是机甲推进追逐。

## 四种常见感觉（描述感觉即可，不是固定套路）

| 感觉 | 一句话 | 常见题材 | 镜头感 | 结局倾向 | 可直接复制的调用示例 |
|---|---|---|---|---|---|
| 拳拳到肉 | 真实重量、没有特效、一招一式看得清 | 现代格斗、写实武侠、军警近战、重型机甲冲撞 | 一镜到底、贴身跟拍 | 倒地、缴械、留势 | `用 $seedance-2-5-fight-director，写15秒雨夜窄巷女拳手对男拳手，16:9，电影写实，一镜到底，要有格挡、落空反击和重击反馈，结尾留势，只输出提示词。` |
| 大招对轰 | 先压着打、再蓄力反推、一招定胜负 | 仙侠 3D 国漫 CG、主炮/护盾决胜的科幻 | 分镜快切＋决胜唯一升格＋大远景 | 破甲、击退坠势、系统过载 | `用 $seedance-2-5-fight-director，写30秒仙侠剑修对重甲魔修，云海断桥，蓄力大招对波后反推决胜，3D国漫电影级CG，16:9。` |
| 高速追着打 | 两个人实力接近、攻防不停、满场流动 | 仙侠/热血双人兵器战、动力装甲追逐 | 近似长镜头、甩镜俯冲、遮挡转场 | 兵器脱手、护盾打停，不死亡 | `用 $seedance-2-5-fight-director，写30秒女刀客对男枪客的高速均势战，在竹林和吊桥之间打，不要蓄力和慢动作，结尾枪被打飞。` |
| 横扫千军 | 一个人对成片敌人、大范围清场 | 仙人对魔潮、机甲对虫群、火力阵地 | 密集镜头流、高空俯视、奇观递进 | 潮源被毁或地形改变的终局 | `用 $seedance-2-5-fight-director，写30秒机甲战士在沦陷城区应对虫潮入侵，被包围后队友及时救场，双人合力清场，16:9。` |

这些只是口味坐标，不是规定剧情：同样是"横扫千军"，可以是守卫城门、可以是突围撤退、也可以是救援杀到；场景、路线、波段全部按你的描述推导，不会每次都打出同一条路线。

题材与感觉自由组合，渲染画风也可以单独点：3D 国漫电影级 CG（仙侠默认）、2D 水墨硬核、2D 赛璐璐热血、电影写实、3D 机甲史诗。

## 推荐工作流（高控制 30 秒高燃片）

1. 先准备最能约束身份、结构和空间的素材：角色/机体设定图、武器图、场景图（角色图只锁人、武器图只锁武器、场景图只锁环境）；没有图就用 Skill 自动附带的资产图提示词先生成；
2. 把图作为 @Image 参考输入 Seedance 2.5 做图生视频；
3. 需要精确表演调度时再补动作视频（只借指定区间的重心与节奏，不借人物场景）；
4. 多区域、垂直穿层、大规模奇观直接用分段版：段尾用爆光/云层/碎石/掠镜遮挡，后期按遮挡点拼接，每段重复绑定同一批资产；
5. 平台规格（时长、比例、参考素材数量、续写、编辑）以 `seedance-adaptation.md` 与实际入口为准。

## 不满意怎么说（直接用大白话反馈即可）

- "像过家家、不够快、不够凌厉" → 重推为全程高速打法，删蓄力与站桩，加密攻防反馈；
- "后半段乱了/穿云变成大漩涡/结尾很滑稽" → 按平台可行性修：新元素前移、介质穿越重写、高风险机位换安全机位，必要时转分段版；
- "特效一塌糊涂/糊成一团" → 重做特效生命周期与配色，保证不遮人物与接触点；
- "人物变脸、武器变形、动作糊" → 降动作密度、补素材职责锁定或资产图；
- "机甲像人穿纸壳、激光乱射" → 补结构传力、推进惯性、弹道/护盾与热量资源，删随机 HUD 和无来源爆炸；
- "每次出来都一个套路" → 回到剧情重新推导结构，删除与你需求无关的固定元素；
- "换一种打法/换成科幻" → 保留角色和场景，重推坐标或替换题材词汇。
