# 通用战斗语法库（grammar-library）

> 题材无关的动作、受力、空间、转场、机位、特效、声音语法。仙侠/科幻的**词汇**查对应 playbook，本库只管"怎么写才成立"。结构推导见 `core-engine.md`，运镜术语与渲染配方见 `fight-camera-library.md`。

## 1. 动作状态链（七拍）

每个主要交锋满足七拍：

`当前位置与支撑 → 发力/启动 → 攻击轨迹与目标 → 对手应对 → 接触或落空 → 受力结果 → 下一拍可用姿态`

- 明确谁发动、谁接招；双人场景少用连续的"他/她/对方"，用角色名或 A、B。
- 动作衔接以重心、惯性和距离为依据：脚落地才能重新蹬地；单脚支撑时另一脚才可完成踢击；起跳有起点、弧线与落点。悬浮、踏空、空中转向必须由世界观能力解释并可见来源（御剑、法阵、推进器、姿态喷口、磁力靴、缆索、蹬碎的支点等）。
- 写清命中、被挡、擦过或完全落空，避免同一击既被闪开又出现命中效果。对手在威胁出现后才防守，在受力后才退移。
- 兵器归属、握持手、刃尖方向、碰撞位置明确；换手、脱手、断裂与再取回必须发生在画面中。
- 战斗距离由步法或位移改变，不把远处角色瞬间塞到近身；击退多远留相应追击与飞行时间。
- 每个时间段通常一个主要交换，最多附带一个顺势动作；复杂起跳、翻转、落地与恢复需要更长时间（成本表见引擎 §3）。
- 失败动作（攻击被挡、反击落空、冲撞被架停）必须写实存在，它们制造真实感与均势感。
- 这里的动作是影视表演与画面编排，不转为现实伤害教程。

## 2. 受力反馈四通道与尺度分级

放弃"快速出拳、猛烈踢腿"这类抽象动作，改描述蓄力、受力、反馈、状态。每次关键重击从四通道选 2–3 项：

1. **身体**：守势压缩、肩背随力转动、后脚补步、重心失衡、空中姿态、落地缓冲与滚动。
2. **物体/环境**：护甲凹陷、剑身振动、积水沿力向溅出、鞋底推出尘土与沟痕、接触处碎片崩落、断裂方向服从受力方向。
3. **镜头/时间**：接触前极短停顿、命中瞬间冲击帧（白闪/黑场/爆点，配额见 §8）、受控短震、关键一击短促升格、击退后随势拉镜再回正常速度。
4. **声音**：挥动破风 → 接触瞬间材质声与低频 → 余振 → 落地声，因果顺序不能错位。

**尺度分级**（夸张程度服从力量体系）：

| 尺度 | 代表主体 | 受力表现 | 环境响应上限 |
|---|---|---|---|
| 凡人 | 拳手、士兵、枪手 | 踉跄、滑步、单膝跪地 | 水痕、尘线、木器开裂 |
| 武者 | 武侠高手、强化士兵 | 贴地滑行、撞裂木石 | 柱断、墙塌、气劲掀物 |
| 修士/超能者 | 仙侠主角、魔修、异能者 | 凌空击退、穿破建筑、沿地面犁出深沟 | 石台崩碎、山体缺口、云海被冲开 |
| 动力装甲/轻型机甲 | 人形战甲、强化外骨骼 | 推进偏移、装甲凹陷、关节过载、姿态喷口补偿 | 甲板凹陷、掩体破裂、尾焰与碎屑沿矢量扩散 |
| 巨兽/重型机甲 | 妖兽、魔像、重型机体 | 多足撑地仍被推动、结构件变形、机械迟滞 | 地面龟裂、步震、烟尘柱 |
| 群体波次 | 魔潮、虫群、无人机群 | 密度空缺、编队缺口、潮线凹陷、单位沿力向爆散 | 覆盖物被犁出空带、堆积物位移 |

材质响应必须匹配：裸拳与布料不出金属火花；冷兵器交击可有短促金属音与少量火星；法术/能量对撞出光爆、冲击波与粒子，不是电焊火花；水花、尘屑不跨场景自动添加。非接触震飞必须写明冲击波/气劲何时到达、如何传播。通常只突出一至两个"英雄重击"，小动作轻、决定性攻击重。

**受力方向必须有空场（实测归纳）**：写击退、踢飞、撞落前先检查受力者当前位置与飞退方向——若他身后紧贴巨石、墙沿、崖边，就不能再写"倒飞撞上该障碍"；起点与落点重合时，模型会把人定在原地拍成静态造型。落点障碍放在飞行路径前方、写明飞行距离与缓冲；起点已无空场时，先安排一个位移波段把人打到开阔处再给重击。

## 3. 反馈链目录（攻防衔接的通用单元）

均势战斗的最小单位是反馈链，不是单次交锋。从下列单元拼接，相邻单元不重复：

- 格挡 → 偏转刃线 → 侧闪 → 反攻
- 攻击 → 对方卸力 → 借力变向 → 追击
- 高速碰撞 → 双向弹开 → 重新追击
- 佯攻 → 封死退路 → 命中
- 远程压制（射击/法术点放）→ 对方掩体换位 → 突进缩短距离
- 冲撞 → 被架停 → 角力 → 一方支点破坏 → 推开
- 被连击压制 → 一次成功防御 → 打断对方节奏（肘/膝/肩撞）→ 抢回攻击角度
- 合围收缩 → 一次范围手段打出缺口 → 向缺口突围
- 救援：被围者受压 → 救场火力/冲击从明确方向切入 → 双方视线或弹道关系交代 → 合流后分工（一人破点、一人牵制）

均势要求：双方主动发起次数大致等量；任何一方不连续当木桩超过一个波段；追逐战中追逐方必须在追逐中出招。

## 4. 空间调度语法

每个调度单元都要写清：起点位置、路径与方向、支点或动力来源、过程中的前景参照、落点与落后面向。

- **接近/冲刺**：初始距离、缩短路径、步法或推进方式、前景视差；到达后才有近身动作。
- **交错/擦身**：谁从谁的哪一侧掠过、掠过后各自朝向与屏幕位置；交错瞬间可埋一次交换。
- **爬升/升空**：每一层高度的支点（柱、剑体、法阵、喷口、缆索、蹬碎的浮石）、上升弧线、高度参照物；禁止无支点连续腾空与垂直漂浮。
- **坠落/俯冲**：朝向、前景高速掠过物、加速参照、接地或接入时的缓冲动作；坠落中交手要写身体朝向如何改变。
- **追逐**：前后位置如何变化、路径收窄或障碍、速度参照物；追逐必须有终点（追上、拦截、汇入新区域或目标达成）。
- **合围**：包围方向数、压力如何收缩、缺口在哪、被围者的近失；合围是动态收缩，不是站成一圈。
- **突围/救场切入**：缺口或外力从哪个方向来、被围者与救场者的视线/弹道关系、合流后的分工与背靠背方位。
- **弹道/投射物**：发射源 → 传播（尾迹、掠过物、先后顺序）→ 与护盾/装甲/目标相遇 → 响应 → 余态（后坐、过热、弹药变化）。禁止"发射源一亮，远处同时爆炸"。

### 介质层穿越通用三段式（云、烟、雾、水、火幕、沙暴、能量幕共用）

这是实测高翻车点，必须按三段写：

1. **先写介质几何**：介质是水平铺展的层（云海、湖面）还是竖立的墙（烟墙、瀑布、火幕）；人物当前在介质的哪一侧；介质边界在哪里。
2. **穿入**：人物从明确方向进入，介质被撕开或排开（写排开方向），画面被介质**短暂遮满 0.3–1 秒**作为转场。
3. **穿出**：露出新一侧的空间关系——若到了介质"上方"，镜头必须朝下看见介质表面与人物的高度关系；用一两个已建立锚点重新定向。

红线：

- 禁止把介质写成漩涡、涡眼、对称双涡、传送门、竖立云墙、环形空洞（除非剧情明确就是传送门）；"空洞"只能写为冲击波造成的**瞬时回弹凹陷**，不写持续张开的洞。
- 禁止人物停在介质前静止悬浮；禁止只写"到达云层/水面上方"的结果而不写穿越过程。
- "穿到介质之上再俯瞰原点俯冲返回"是三段垂直调度，超出单段能力框，直出版只写单层穿越，完整版走分段（引擎 §7）。

## 5. 遮挡转场库

隐形切镜与分段拼接的首选衔接。用法：遮挡物在动作趋势中自然掠满画面（≤1 秒），切后延续六字段状态。

- 身体类：交手双方身体掠过、披风/旗、敌群个体冲镜、载具外壳。
- 介质类：云雾、水花、烟尘、爆光、火焰、雪幕、能量幕。
- 结构类：柱、门框、桁架、墙体、廊柱、树干。
- 暗场：冲击帧白闪/黑场（全片配额见 §8），不可连续使用。

切镜纪律：切点接在动作趋势上；切后第一帧交代位置与朝向；每镜一个叙事目的（建立空间/展示威胁/读出攻防/释放重击/呈现结果，五择一）。

**满画遮挡实测纪律**："遮满画面"极易被模型照字面执行成整屏水墙、白屏或近一秒黑糊。直出版默认让遮挡物横划掠过、遮住约三分之二画幅，画面边缘保留主体运动轮廓或前景物（木板横划、芦苇扫镜、身体局部掠过）；确需满画只给 0.3–0.5 秒并保留掠过物的运动残影，同一段满画遮挡不超过一次。

## 6. 机位可行性黑白名单

| 高风险调度（默认禁用） | 实测失败表现 | 安全替代（默认写法） |
|---|---|---|
| 镜头绕弧 180°＋A 高速掠过停到 B 身后 | 主客颠倒：A 变前景时装定格、B 蹲在 A 身后右方，观感滑稽 | 正侧面固定机位，两人同向侧影；A 停在 B 后方半步，镜头不越轴；或 A 掠过、B 单膝落地后镜头固定在两人侧面中景 |
| 脱手武器旋转飞出、插到远处 | 小物体消失或原地竖立 | 武器朝屏幕指定方向脱手，全程在画，1 秒内落入画面内地面/甲板并弹一下停住，给尺寸参照 |
| 同帧双向高速交叉后要求精确落点 | 位置重置、朝向错乱 | 交叉后半秒同向滑行减速，再分别停住，用锚点重新定向 |
| 长时长垂直穿层后精确返回开场点 | 模型新造场景、硬切回地面 | 穿层后不回场（在新层收束）；要回场必须分段，俯冲与落地重战分属两段 |
| 一镜到底中 360°环绕同时读手部细节 | 方位丢失、穿模 | 环绕不超过 180°；手部信息另给固定特写镜，用遮挡衔接 |
| 急推同时要求主体距离不变、一拍内环绕＋推镜＋变焦 | 镜头矛盾、主体变形 | 一拍一个主运镜；复合运镜拆成相邻两拍 |
| 长时间灰雾/黑场过渡 | 近 1 秒空帧、叙事中断 | 遮挡满画 ≤1 秒，遮挡中保留运动残影或掠过物轮廓 |
| 完美圆形/环形敌阵把主角围在正中、主角抬武器定格（实测） | 对称 tableau 凝固约 3 秒，像群演摆拍，流动感中断 | 不对称流动人潮：前方厚、两侧薄、潮线持续移动，主角沿缺口边走边打；全片唯一环形技能 0.8 秒内放完、不摆造型 |
| 连续大远景、角色立于对称构图正中（实测） | 成片像静态原画、镜头不流动，远景之间只能硬切 | 30 秒群战大远景 ≤3 个、每个远景内部有强运动（潮在跑、箭飞、人冲刺），其余为贴人移动的全景/中景，机位随角色路径连续 |
| 收尾只写"胜者站立、败者跪地/倒地"、镜头停住 | 模型默认拍成正面居高临下的 3 秒静态胜利摆拍（实测） | 最后 1–2 秒镜头持续后拉或横移，两人保留余动（喘息、衣发披帛飘动、水面或尘烟余动、武器微颤），静止造型不超过 1 秒；机位写侧后方或正侧面，避开它最熟悉的正面定格图式 |

通用安全原则：越轴必须用可见的连续绕行交代；末帧优先侧面或背面中景，不要求角色正对镜头；决胜后给呼吸、余动、未收回的武器与未平息的环境，不摆胜利姿势。

## 7. 能力与武器系统生命周期

超现实或高科技战斗先声明力的来源，每个技能、武器或防御系统六步齐全：

`能力积聚在已指定部位/器物 → 动作引导能量沿单一主轨迹释放 → 传播（尾迹、粒子、被照亮的环境）→ 与对手力量相遇或命中目标（接触点清晰）→ 身体与环境响应（四通道）→ 衰减消散、战果显露`

科幻等价链：`反应堆/电容/弹仓/推进系统就绪 → 炮口或执行器引导释放 → 弹体/光束/机体沿可读矢量传播 → 护盾/装甲/目标相遇 → 后坐、热量、结构与环境响应 → 冷却、耗散、弹药/故障状态进入下一拍`。

- **对波/对冲**（能量束、主炮角力、水柱对顶通用）：蓄力 → 轰出 → 相遇（交界线落在画面可读位置，如画面 1/3 处）→ 拉锯（交界线向弱势方推移，弱势方给身体反应：犁沟、支撑足刮痕、护盾裂纹、咬牙/报警灯）→ 反推（写清触发动作：换印、第二能源、队友供能）→ 洞穿 → 战果（击退、破甲、脱手、过载）。禁止两条光带僵持不动、对波后毫发无损。
- **护盾/护体**：写明发生器或光膜来源与覆盖扇区；受击先凹陷/涟漪，负荷扩散（裂纹、告警、闪烁），破裂只发生在累积受击后；破裂后果延续到结尾。
- **身法/位移**：御剑、踏空、残影、推进器、磁力靴、缆索都要给可见来源；残像与速度线是运动余迹不是新增实体，残影 2–3 道快速淡出，不变成分身。
- **特效分层**：核心特效（光爆、剑气、火花、能量波纹）绑定命中瞬间；辅助特效（动态模糊、残像、速度线、衣发翻飞、粒子）绑定运动过程。特效不长时间遮住主体轮廓、肢体衔接和接触点；给光效消散时间，不全屏长亮。技能余波只留焦黑裂纹与碎屑，禁止地面残留发光法阵圈或彩色光环；能量染色天空不超过 1 秒、不改变环境底色。
- **色彩纪律**：一场战斗限定一套对立色系（如主角青蓝、敌方暗红），技能形态与角色性格匹配；辅助色少量且不改变主视觉；禁止每技能一色的彩虹轮播。时代错位禁忌见各 playbook。

## 8. 冲击力表达预算

- 全程实时高速片（流动 1v1、群战、追逐）：**禁用 hit-stop 与长慢动作**，冲击靠六件事——亮度脉冲、速度突变、镜头急推与受控短震、环形空间冲击波、环境反馈、受力方位移。决胜处允许一次不超过 0.3 秒的极短微停。**用户明确要求受力特写升格时，该升格必须独占一个节拍**（独立时间区间、不与其他动作挤在同段），慢镜覆盖接触与受力压缩约 1–1.5 秒，飞退、撞物、落地全部回实时。用户要求全屏华丽特效时，峰值允许铺满画面 1.5–2 秒、主体以逆光剪影保持可读（见引擎 §6）。
- 一张一弛片（回合决胜）：冲击帧（白闪/黑场）全片 ≤1 次、短促升格（约 0.4–0.5 倍速）全片 ≤1 次、Crash Zoom 限决胜波段；蓄力段是全片最低速点，反推是全片最高速点。
- 写实片：不用白闪与升格，只用接触前极短停顿、接触后受控短震与随势拉镜。
- **短促升格实测写法**：升格只覆盖"命中接触那一瞬"约 0.3–0.5 秒屏内时间（写明"命中瞬间慢放半秒，脚一蹬实立刻回实时"）；受力者的倒飞、犁地、撞落、缓冲全部在实时速度中完成，慢放段不承载位移全过程，否则模型会把整段反馈拍成持续数秒的定格造型。升格前一镜必须交代飞退方向有空场（见 §2）：踢击点选开阔处、身后不留紧贴障碍，落点障碍在飞行路径前方而不是起点身后。
- 命中先于震动、音效、冲击帧和受力后果；音乐卡点对齐接触或反转，不给每个鼓点强塞一招。

## 9. 环境参战与破坏分级

环境是力量标尺，破坏随波段升级、不提前透支，残骸持续保留到结尾：

1. **微动**：衣发、落叶、积水、灯火、尘雾被气劲吹动。
2. **表面伤**：脚下裂纹、踏碎石台、表面斩痕、甲板凹陷。
3. **局部断裂**：斩波断柱、掩体碎裂、栏杆崩落、管线喷泄。
4. **结构塌陷**：整段桥面/楼板/桁架坍塌、巨石崩落、墙体洞开。
5. **地形改变**：冲击波环形扩散改变整片地形、云海/水面被冲开、潮源崩塌；只用于终局。

破坏方向服从受力方向：人向右飞，碎屑、尘浪、镜头运动主方向一致；垂直重击地面下陷、裂纹放射；横扫让物体横向翻滚。

## 10. 声音五层

按五层写：现场底噪（风、雨、雷、云海、舱体共振、无线电底噪）→ 发力与运动（衣料、脚步、呼喝、剑鸣、伺服、推进）→ 接触材质与系统声（金属、闷响、碎裂、法术嗡鸣、供弹/充能/报警）→ 余势/落地/散热（滚落、坠渊、余振、冷却排气）→ 音乐起伏。

- 对波/决胜前音乐收束（可近乎静音），反推或命中时爆发，胜负落定后音乐收住，留环境声与喘息/设备声。
- 默认无对白、无字幕、无战吼、无技能名；发力呼喝属于动作音。用户指定对白、原声、无 BGM 或全静音时完整覆盖。
- 拟声词（CLANG、SWOOSH、CRUNCH）只作辅助，中文自然语言为主；没听到音频不假称解析了 BPM。

## 11. 高速现象词库（按需取用）

残影、速度线、背景高速后掠、边缘动态模糊、脚步连环炸开的水花/尘屑、衣发与长缨被拉成直线、前景物高速掠过、尾焰/灵力尾迹拉长。高速段主体仍须清晰：脸、手、武器与接触点不拖影不变形，动态模糊只给背景与边缘。
